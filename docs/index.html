Seismic Analysis
In One Box.

SeisBox is a modern, cross-platform native desktop suite for interactive seismic data analysis. Experience real-time waveform tuning, map-based Coulomb stress modeling, SESAME-certified HVSR analysis, and lightning-fast FDSN data acquisition through an intuitive Graphical User Interface.

Everything you need for seismic analysis

A comprehensive toolkit designed for researchers and practitioners.

🚀

Launcher Hub

The central dashboard to manage workspaces and seamlessly launch all 8 SeisBox modules.

📊

HVSR Analysis

Real-time HVSR tuning with STA/LTA screening, Konno-Ohmachi smoothing, and strict SESAME (2004) criteria evaluation.

🔬

Velocity Inversion

Invert HVSR or Ellipticity curves into 1D S-wave velocity profiles using RJ-MCMC, PSO, LM, or Occam algorithms.

⚡

Coulomb Stress

Compute static stress changes interactively with map viewers, depth cross-sections, and real-time fault parameter sliders.

📌

Phase Picker

Load and visualize SAC/MiniSEED waveforms with interactive zoom, multi-trace display, and precision phase picking tools.

📡

FDSN Client

Interactively search and download waveforms via global FDSN webservices, with built-in map station selectors and real-time preview.

🌐

ISC Client

Download and filter earthquake catalogs and hypocenter parameters natively from the International Seismological Centre.

📈

Stats Viewer

Perform advanced seismicity statistics, Bayesian Voronoi b-value mapping, and magnitude-time evaluations.

🗺️

Grid Interpolation

Process spatial data arrays with configurable interpolation algorithms for contour mapping and surface rendering.

Get Started

Up and running in under a minute.

1

Download

Go to the GitHub Releases page and download the executable for your operating system (macOS, Windows, or Linux).

⬇ Latest Release
2

Extract & Install

Extract the downloaded archive to your preferred directory. (For macOS users, you may need to bypass the security prompt or run a provided quarantine fix script).

3

Launch SeisBox

Run the seisbox_launcher executable and start analyzing your seismic data!

Build from Source

git clone git@github.com:yudhastyawan/SeisBox.git
cd SeisBox
chmod +x compile_dist.sh
./compile_dist.sh

Requires Rust 1.70+.
